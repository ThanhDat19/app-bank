## Phạm vi hiện thực

- RFC 9457 `ApiProblem`, stable code, validation fields, safe 500, giữ HTTP/Allow headers phù hợp.
- Correlation filter cho request/error/async dispatch, chọn ID an toàn, response header và MDC cleanup.
- BusinessException contract thuần Java, mapping kind sang 404/409/422 ở adapter.
- Swagger error annotation + correlation header customizer; spec được kiểm tra qua HTTP thực.
- Architecture rules cho dependency cycles, module application boundary, shared và pure domain.
- [Đặc tả API](../api/conventions.md), [quy tắc module](../architecture/module-boundaries.md).

Không có API demo trong production, không có Customer/IAM/ghi tiền và không thay schema/migration.
