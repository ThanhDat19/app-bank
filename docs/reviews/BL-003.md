## Tự phản biện và cải thiện trong phiên

- JWT fixture hợp lệ chưa chứng minh token thật có đủ claims. Kiểm chứng ban đầu với Keycloak phát hiện
  401 dù audience/type đúng. Dùng IntelliJ non-suspending logpoints xác nhận `subjectMissing=true`.
  Client đã bỏ default scopes nên thiếu scope `basic` chứa mapper `oidc-sub-mapper`. Đã thêm `basic`
  vào realm JSON và gắn vào client local hiện hữu, giữ nguyên realm/user/volume. Sau sửa, logpoint cho
  `subjectMissing=false`, type Bearer/audience đúng; real login vượt qua. Giữ nguyên validator bắt buộc sub.
- Không mặc định thiếu PKCE phải trả HTTP 400. Keycloak trả 302 về callback với `invalid_request`, state
  đúng và không có code; smoke test kiểm tra đầy đủ phản hồi OAuth này. Wrong verifier bị token endpoint từ chối.
- Swagger PKCE setting nằm trong `swagger-initializer.js`; test đọc đúng asset được phục vụ, thay vì
  giả định nó xuất hiện trong swagger-config JSON.
- Web slice tests cũ không có HttpSecurity context: thêm test-only configuration với EnableWebSecurity;
  full integration vẫn chạy production chain. Không dùng permit-all để làm security tests xanh.
- Không để catch-all MVC chuyển AccessDenied/Authentication exceptions thành 500: thêm mapping riêng và
  test method-security qua HTTP. Không tạo operations demo endpoint trong production để chứng minh role gate.
- Logpoints của agent đã gỡ và debug process đã dừng; giữ nguyên năm exception breakpoints của owner.
