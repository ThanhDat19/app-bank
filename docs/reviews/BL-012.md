## Scope và acceptance

| Requirement | Evidence |
| --- | --- |
| Journal/event/delivery cùng commit | OutboxIT: chưa commit không claim được; commit thấy exact envelope |
| Event insert failure không tạo tiền | Constraint fault rollback journal/postings/event; cùng reference retry thành công |
| Financial receipt deferred fault | Pending cash-in receipt không commit được, event/delivery cũng rollback |
| eventId/aggregateVersion/schemaVersion/privacy | Exact journal/header/time, amount string, không actor/JWT/reason/profile |
| Concurrent workers | 8 workers claim 16 events, không trùng claim |
| Crash recovery/fencing | Lease expiry → claim token mới, attempt tăng; token cũ không ack/requeue được |
| At-least-once | Giả lập transport accepted rồi không ack; reclaim gửi lại chính eventId/payload cũ |
| Ack DB fault | Accepted rồi ack constraint fail; lease recover và redeliver cùng eventId |
| Retry | Publisher failure requeues với backoff; không claim sớm, lần sau thành công; delay capped |
| No network under DB transaction | Publisher callback assert no actual transaction; ambient transaction bị từ chối |
| Immutable event/terminal delivery | SQL update/delete/reopen bị reject |
| V9 → V10 | Giữ posted money/journal cũ, không backfill; forged payload bị reject; new journal auto-enqueues |
| Configuration | Scheduling mặc định tắt; enabled thiếu publisher fail startup |
| Baseline/package | Banking/security/migration baseline đạt; V10 và tất cả production classes trong JAR |

## Review limits

Xem [ADR-005](../architecture/ADR-005-transactional-outbox.md) và [local guide](../development/local-outbox.md).
Aggregate=immutable journal/version1, không account/global ordering. Một logical destination;
principal/fee events có thể đến khác thứ tự. No backfill hoặc automatic cleanup, chưa Kafka/dedupe/DLQ.
Relay default off; bật bắt buộc publisher thật, không logger/no-op. Owner review transport acceptance contract,
lease/batch sizing, privacy và retention trước vận hành. Owner giữ quyền approve/merge; issue vẫn mở đến nghiệm thu.
