## Review limits

[ADR-008](../architecture/ADR-008-history-statements.md) · [API](../api/history-statements.md) ·
[Local guide](../development/local-statements.md).

Snapshots are explicit non-idempotent POST read artifacts with no automatic cleanup/quota/listing. Default cap
10000, server bounds 1–100000; generation timeout 30s, no silently truncated READY result. CSV contains entry rows;
header/range/zone/opening/closing metadata is separate. Java IANA timezone rules are conversion authority; effective
end caps at DB transaction time. Historical signed amounts are not current/available balance, value-date settlement
or a certified statement. Amount bytes stay exact; downstream spreadsheet auto-conversion is outside the API contract.
No financial writes/source repair, counterparty identities, JWTs, reasons or extra profile data. Central V12 audit
scope is unchanged; no SSE here. Owner controls review/merge/issue state.
